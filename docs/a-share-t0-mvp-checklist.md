# A股T+0训练系统 MVP 验收清单

## 功能验证

- [ ] 股票 / ETF / 可转债均可下单，手数规则分别生效（100/100/10）。
- [ ] 价格校验按标的生效（股票/ETF ±10%，可转债 ±20%）。
- [ ] 大单触发部分成交，订单状态进入 `partial`，剩余数量继续挂单。
- [ ] 交易页可看到实时行情来源、标的类型、手数、涨跌停范围。
- [ ] 挑战大厅可发起挑战并写入 `sim_challenge_runs`。
- [ ] 行为雷达展示天赋总分、四维评分、标签与改进建议。
- [ ] 排行榜可展示最近高分挑战记录。

## 数据与稳定性

- [ ] `TUSHARE_TOKEN` 存在时优先使用 Tushare，缺失时自动回退行情源。
- [ ] 行情与训练 API 在高频轮询下无明显超时与报错。
- [ ] `sim_order_events` 可记录 submitted/matched 事件用于回放。

## 性能与体验

- [ ] 下单交互 3 秒内完成反馈（成功、部分成交、挂单、失败）。
- [ ] 页面首次加载包含账户、持仓、训练评分，15 秒刷新训练数据。
- [ ] 新用户 10 分钟内可完成：下单 -> 参与挑战 -> 查看评分建议。
