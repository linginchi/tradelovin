# 视频页三卡片分区（交易经典 / 录播教学 / 课程直播）

**日期：** 2026-07-31  
**状态：** 待实现（方案已确认）  
**入口：** 前台 `/courses`（首页「订阅视频」入口不变）

## 背景

当前 `/courses` 扁平列出全部活跃课程，没有分区。产品要求视频页首屏改为三张卡片，再进入对应课程列表。

## 分区映射（已确认）

| 卡片标题 | 内容 | 行为 |
|---------|------|------|
| 交易经典 | `豹哥·交易新銳` + `豹叔·交易經典` | 进入课程列表 → 详情/播放 |
| 录播教学 | 第 1–5 课（现有五门录播课） | 同上 |
| 课程直播 | 暂无课程 | 进入后仅展示「敬请期待」，不造假课 |

未纳入三卡的活跃课（如「A股基础知识」）仍可由直链/后台访问；**不出现在三卡分区列表里**。

## 方案

复用现有 `course_topics` + `courses.topic_id`（后台已支持绑定）。前台按 topic 分组展示；不做硬编码课程 ID 列表作为唯一来源（种子映射可写在 migration/SQL，运行时读 DB）。

### 数据

1. **Topic 重整**（生产一次性 SQL / migration）：
   - 确保存在且 `is_active=true` 的三个 topic（标题以产品文案为准）：
     - `交易经典`（`sort_order=10`）
     - `录播教学`（`sort_order=20`）
     - `课程直播`（`sort_order=30`）
   - 旧 topic（`股票交易` / `豹哥·交易新銳` / `豹叔·交易經典`）：课程迁出后可 `is_active=false` 或删除（删除会 `ON DELETE SET NULL`，故须先改绑）。推荐：**改绑后将旧 topic 置为 inactive**，避免误用。
2. **课程改绑**：
   - 交易经典 ← 豹哥、豹叔
   - 录播教学 ← 第一课…第五课
   - 课程直播 ← 无课程
   - 「A股基础知识」：`topic_id = null`（或不绑上述三卡）
3. **不改** `content_kind` 语义（若列存在则保留；本功能不以它为前台筛选键）。

### API

1. **公开** `GET /api/course-topics`（或扩展现有公开 courses API）：
   - 返回 `is_active=true` 的 topic：`id, title, description, sort_order`
   - 可选：附带 `courseCount`（课程直播为 0）
2. **公开** `GET /api/courses`：
   - 增加可选查询 `?topicId=<uuid>`：仅返回该 topic 下 `is_active` 课程
   - 响应每条课程带上 `topic_id`（便于客户端分组/校验）
   - 无 `topicId` 时：保持「全部活跃课」行为（后台/兼容），**前台视频首页不再用无参列表作为首屏**

### 前台 UI

1. **`/courses` 首屏**：三张分区卡（标题 + 一句短说明；课程直播说明可为「敬请期待」）。
2. **点击交易经典 / 录播教学**：同页切换或 `?topic=<id>` 进入该 topic 的课程列表（沿用现有课程卡样式：标题/模式/日期/查看）。提供返回分区的入口。
3. **点击课程直播**：进入占位态（文案「敬请期待」），无课程列表、无假报名 CTA。
4. **深链**：`/courses?topic=<uuid>` 直达分区列表；非法/未激活 topic → 回退首屏三卡并提示或静默回退。
5. **i18n**：`messages/{zh,zh-TW,en}.json` 的 `CoursesPage` 增加卡片标题与占位文案键；DB topic 标题以中文产品名为准，UI 优先用文案键映射（按 `title` 或稳定 `sort_order`/`slug`）。若暂无 slug 列，用 **固定 sort_order + 文案键** 映射，避免依赖可变 DB 标题做 i18n。

### 权限与播放（非本变更范围，但验收相关）

- 访客预览门禁不变：`is_free_preview` + 客户端 10 秒（第 1–5 课已开启）。
- 豹哥播放依赖 R2 对象存在；缺文件时与本 UI 无关，需运维重新上传。

## 非目标

- 不新建 `/videos` 站点级路由
- 不做直播排期/预约
- 不改播放器、报名、支付
- 不在本迭代实现豹哥人气 boost（另有 design）

## 验收

| 检查 | 期望 |
|------|------|
| `/courses` 首屏 | 仅三张卡：交易经典、录播教学、课程直播 |
| 交易经典 | 列表恰为豹哥 + 豹叔 |
| 录播教学 | 列表恰为第 1–5 课 |
| 课程直播 | 「敬请期待」，无课程行 |
| 深链 `?topic=` | 可直达对应分区 |
| 游客点录播任一课 | 仍可 10 秒试看（数据已就绪） |
| 旧扁平「一次列出全部课」 | 不再作为视频首页默认 |

## 风险与回滚

- **风险：** 旧 topic 标题与后台运营习惯不一致 → 后台课程编辑需重新选 topic。  
- **回滚：** 恢复 `topic_id` 快照；前台恢复扁平 `CoursesListClient`；可保留公开 topics API（无害）。
