## 1. Problem

T0 考核盘已有成交计入 TQ，学习页也有雷达卡，但两条训练入口（T0、量化实验室）都没有「本模块的考核仪表」：学员看不清自己在这个模块的水平，点进去也得不到「从哪开始 / 该加强哪项训练」的下一步。

## 2. Goals

1. **每个模块一块考核仪表盘**：T0 训练盘、量化实验室各一块，位置在该模块入口/工作台显眼处。
2. **反映学员水平**：以 **TQ 分数** 为主读数（总分 + 维度），学员只能看自己的。
3. **可点击**：点仪表不只看分，还给出提示——冷启动时「从哪开始」；有分时「要加强哪些训练」。
4. **命名**：入口 B 对外称 **量化实验室**（不再用「AI 实验室 / AI 研究实验室」当主名）。文案切换可并进本项或实验室收口时一起改。

## 3. Non-Goals（本项）

- 现在就改代码、加表、做 UI。
- 给教练做全班对比大屏（可后置）。
- 新建第二套与现有 `tq_scores` 平行的 T0 引擎。
- 改魔法链接、自定义域名、`NEXT_PUBLIC_SUPABASE_URL`。

## 5. 推荐做法

**同一套仪表壳，两个数据适配器。**

- 壳：总分、四维（或模块相关维）、冷启动状态、点击后的「下一步」列表。
- **T0 适配器：** `environment=sim` 的 TQ（默认月度，与考核盘一致）+ 现有 advice 模板；提示链到操作练习、考核盘资源/成交、课程 `course_hint`。
- **量化实验室适配器：** 同一 TQ 读数作水平；提示链到「做一次组合诊断 / 看历史报告里的风险主题」。实验室专属分（若有）等 P0 跑出真实会话后再加，不在第一版发明。

不推荐：两套完全不同的仪表；也不推荐为实验室立刻新造评分引擎。

## 6. UX 约束

- 学员只看本人；RLS / `requireTradeUser` 与现有 TQ API 一致。
- 冷启动（成交不足 / 尚无实验室会话）：仪表显示「还不能打分」+ **从哪开始**（T0：操作练习→考核盘；实验室：准入与第一次诊断），不要空白。
- 点击展开（面板或抽屉，不要新开一套独立产品站）：弱项维度 → 对应训练入口。建议不荐股、无实盘。
- `/api/tq/advice` 目前对部分低档会员 403。仪表若对 T0 学员开放，第一版要明确：T0 是否只看分、建议是否降级为固定文案。默认倾向：**看分对本人开放；可执行建议按现有会员门槛**，避免把付费建议泄漏进 T0。
