2. 界面对照（示意图）

资源页：左「教练可发放库存」≠ 右「个人资源额度」（真正能开仓的数量）。申请后要等教练批准。

3. 第一次打开

  1. 登录账号。
  2. 点导航「TO交易训练」，进入 /trade。
  3. 确认顶栏是「考核盘（模拟）」，并看到本月 TQ 进度。
  4. 阅读弹出的操作指引。以后可点「帮助」再看。
  5. 建议先点一次「操作练习」，走完「资源申请」关，再回到本页做考核。

4. 最关键：先找金钱豹教练申请额度

额度由教练设置并批准，后台不逐笔审批。开仓只扣个人额度。

申请步骤

  1. 滚到「资源」，选择金钱豹教练并申请绑定，等对方接受。
  2. 点左侧「教练可发放库存」那一行选标的。
  3. 在本面板「申请数量（股）」填数量，例如 1000。
  4. 做多点「申请多头额度」；做空点「申请空头额度」。
  5. 个人表要等教练批准后才会出现记录，才能按同一方向下单。
教练在 /coach 设置库存，也可直接发放。管理员只在 /cjkzt/instructors 任命教练，不批每一笔额度。

5. 做多 / 做空（逐步）

做多

  1. 交易模式选「做多」。
  2. 个人多头额度 ≥ 下单股数。
  3. 点盘口卖价填价格，或手填大于 0 的价格。
  4. 点「买入」。
  5. 「委托」看已成交 / 已挂单 / 已拒单。
  6. 平多：仍做多，点「卖出」，数量不超过仓位可用。

做空

  1. 交易模式选「做空」。
  2. 个人空头额度 ≥ 下单股数。
  3. 填价格和数量。
  4. 点「卖出开空」（不是做多里的卖出）。
  5. 仓位出现空头后再回补。
  6. 回补：保持做空，点「买入回补」。

6. 看结果与评分

  • 委托：当日订单。拒单可点「去申请额度」。
  • 仓位：当前持仓。可用为 0 时不能平。
  • 成交：计入 TQ。
  • 顶栏 TQ：大约满 10 笔才出有效分。P0 升 T1 门槛约 60 分。完整进度在会员中心。
  • 操作练习的记录不会写入考核委托，也不会扣个人额度。

7. 失败时看「原因 + 下一步」

你看到先做什么
空头/多头额度不足等教练批准个人额度到账后再下单
请先选择金钱豹教练资源面板绑定教练
教练库存中不存在该标的点教练库存已有行，或请教练加入
价格必须大于 0点盘口价格，或手填价格
资金不足打开「账户」，减少数量或先平仓
无可卖仓位先买入开多并成交
已挂单等成交，或把价格改近现价
撮合通道拥堵模拟风控随机拦截，稍后再试

8. 测试反馈

顶栏橙色「测试反馈」，或右下角大按钮「测试遇到问题？点此反馈」。

  1. 用自己的话写：刚才点了什么、期望什么、实际看到什么。
  2. 可填微信 / 邮箱 / 手机，可上传截图（不超过 3MB，会作为邮件附件送达）。
  3. 下方「自动诊断信息」不要删，里面有标的、额度、最近拒单和失败提示。
  4. 提交。

9. 建议测试路径（约 10 分钟）

  1. 打开 /trade，看到考核盘和 TQ。
  2. 不申请额度就做空下单 → 应被拦住并跳到资源。
  3. 绑定教练，点库存标的，申请空头 1000 → 待批准 → 教练批准后个人表出现记录。
  4. 再开空 → 不应再因额度被拒。
  5. 点测试反馈，确认诊断里有标的和最近失败。
  6. 可选：走一遍操作练习，确认不产生真实委托。
