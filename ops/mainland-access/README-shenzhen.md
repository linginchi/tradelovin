# 深圳部署方案（含 ICP 备案）

适用于长期稳定的内地访问需求，完全合规。

## 架构

```
内地用户 -> 阿里云深圳服务器（备案域名）-> Cloudflare Worker -> Supabase
```

## 前置要求

1. **域名**：必须是中国大陆域名（.cn / .com.cn / .中国）
2. **备案**：必须通过阿里云 ICP 备案系统完成备案
3. **服务器**：阿里云中国大陆境内节点（深圳/上海/北京等）

## 完整流程

### 阶段 1：准备资源（1-2 天）

#### 步骤 1：创建深圳轻量服务器

1. 登录阿里云控制台
2. 切换到 **中国大陆** 地域（如深圳）
3. 创建轻量应用服务器：
   - 镜像：Ubuntu 22.04
   - 套餐：最低配即可
   - **重要**：服务器创建后记得开通安全组，开放 22/80/443 端口
4. 记录公网 IP 地址

#### 步骤 2：注册/转移域名

1. 在阿里云注册 .cn 或 .com.cn 域名
2. 或从其他注册商转移域名到阿里云

**推荐域名格式**：
- `tradelovin.cn`（简短好记）
- `tradelovin.com.cn`（体现品牌）
- `tradelovin-tech.cn`（如果主域名已被注册）

---

### 阶段 2：ICP 备案（7-20 天）

#### 步骤 3：提交备案申请

1. 登录阿里云 [备案系统](https://beian.aliyun.com/)
2. 选择 **"首次备案"** 或 **"新增网站"**
3. 填写信息：
   - **网站名称**：TradeLovin 技术平台（需符合命名规范）
   - **网站类型**：企业/个人（按实际选择）
   - **网站内容**：非经营性互联网信息服务
   - **服务器**：选择刚创建的深圳服务器
   - **域名**：填入你注册的 .cn 域名

4. 上传证件：
   - 身份证正反面
   - 人脸识别（阿里云 App）
   - 网站负责人信息

5. 提交后等待审核：
   - 阿里云初审：1-3 个工作日
   - 工信部审核：7-20 个工作日

#### 备案期间注意事项

- **备案期间网站无法通过域名访问**
- 如需紧急测试，可通过 **IP 地址** 临时访问（但不安全，仅测试用）
- 建议等待备案完成后再通知同事正式使用

---

### 阶段 3：部署上线（备案通过后）

#### 步骤 4：配置 DNS

备案通过后，在阿里云 DNS 解析控制台添加记录：

| 记录类型 | 主机记录 | 记录值 | TTL |
|---------|---------|--------|-----|
| A | @ | 深圳服务器IP | 600 |
| A | www | 深圳服务器IP | 600 |

#### 步骤 5：服务器部署（备案期间 IP 临时测试）

SSH 登录深圳服务器后，把仓库里的 `ops/mainland-access` 目录同步到服务器并执行：

```bash
cd /opt/tradelovin/ops/mainland-access
chmod +x setup-cn-phase1-ip.sh setup-cn-phase2-domain.sh verify-mainland-proxy.sh

# 备案期间：先用 IP 入口给内部同事测试
./setup-cn-phase1-ip.sh <worker-host>
./verify-mainland-proxy.sh <深圳服务器IP> <worker-host> http
```

示例：

```bash
./setup-cn-phase1-ip.sh tradelovin.mark-377.workers.dev
./verify-mainland-proxy.sh 47.88.10.20 tradelovin.mark-377.workers.dev http
```

#### 步骤 6：备案通过后切换域名 + HTTPS

```bash
# 备案通过并完成 DNS A 记录后执行
./setup-cn-phase2-domain.sh <你的备案域名.cn> <worker-host>
./verify-mainland-proxy.sh <你的备案域名.cn> <worker-host> https
```

## 常见问题

### Q1: 备案期间想提前测试怎么办？

可以通过 **IP 地址** 临时访问：
```
http://<深圳服务器IP>
```

但注意：
- 仅用于内部测试
- 不要分享给外部用户
- 备案通过后必须切换回域名访问

### Q2: 备案被驳回怎么办？

常见驳回原因：
1. **网站名称不合规** - 修改后重新提交
2. **内容描述不清晰** - 补充说明网站用途
3. **证件照片模糊** - 重新拍摄上传
4. **电话号码无法接通** - 确保备案期间电话畅通

### Q3: 备案通过后还需要做什么？

1. 在网站底部添加 **ICP 备案号**（法律规定）
2. 定期登录备案系统确认信息准确
3. 如服务器/域名变更，需及时更新备案

### Q4: 深圳和香港服务器怎么选？

| 对比项 | 深圳（备案） | 香港（免备案） |
|-------|-------------|---------------|
| 合规性 | ✅ 完全合规 | ⚠️ 灰色地带 |
| 访问速度 | ✅ 内地更快 | ⚠️ 略慢 |
| 稳定性 | ✅ 非常高 | ⚠️ 可能波动 |
| 实施周期 | ❌ 需 7-20 天 | ✅ 立即可用 |
| 长期成本 | ✅ 低 | ✅ 低 |

**建议**：
- **长期正式使用** → 选择深圳 + ICP 备案
- **紧急临时测试** → 选择香港（无需备案）
