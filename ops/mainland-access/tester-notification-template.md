# 内地同事测试通知模板

可直接复制到企业微信/飞书群：

---

TradeLovin 内地测试入口已就绪，请使用以下地址测试：

- 测试域名：`https://<your-domain.com>`
- 备用网址：`https://www.<your-domain.com>`

建议验证：

1. 首页是否可正常打开（无明显白屏/样式丢失）
2. 登录是否正常
3. 关键业务页面（课程、交易、后台）是否可访问
4. 提交一个最小操作（如下单/报名/更新资料）是否成功

若发现问题，请附上：

- 访问时间
- 所在城市和网络（移动/联通/电信/公司宽带）
- 错误截图
- 浏览器与版本
